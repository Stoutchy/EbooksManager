# 📚 Gestionnaire d'ebooks

Un gestionnaire d'ebooks léger et gratuit, avec interface graphique en grille d'icônes (style explorateur Windows).  
Permet d'ajouter des dossiers, de rechercher par nom ou par numéro de tome, et d'ouvrir les fichiers en double-clic.

---

## ✨ Fonctionnalités

- **Affichage en grille** : icônes colorées + nom du fichier en dessous.
- **Barre de recherche** : filtre en direct sur le nom du fichier (insensible à la casse).
- **Recherche par tome** : champ dédié pour trouver `tome 1`, `T01`, `volume 2`, ou simplement `1`, `2`, `3`… (avec ou sans préfixe).
- **Sauvegarde automatique** : les dossiers ajoutés sont conservés dans `settings.json`.
- **Molette de souris** pour faire défiler la grille.
- **Menu contextuel** : ouvrir, ouvrir le dossier contenant, retirer de la liste.
- **Raccourci clavier** `Ctrl+F` pour focus sur la barre de recherche.
- **Multi-format** : PDF, EPUB, KPF, AZW, AZW3, TXT, CBZ, CBR.

---

## 📁 Formats supportés

| Format | Description |
|--------|-------------|
| `.pdf` | Format statique, mise en page fixe |
| `.epub` | Format dynamique (reflowable) |
| `.kpf` | Format Kindle Package |
| `.azw` / `.azw3` | Formats Kindle |
| `.txt` | Texte brut |
| `.cbz` / `.cbr` | Bandes dessinées (archives d'images) |

---

## 🛠 Installation

### Avec Windows

1. **Télécharger** le fichier `ebooks_manager.exe`.
2. **Execute** le fichier `ebooks_manager.exe`.
